# NeonTech Discount System

I implemented this by creating a web-based discount system for tech products. The goal was to provide users with an intuitive interface to select products, apply discounts based on their roll number and promotional codes, and view their total cost.

## Features

- **Responsive Design**: The layout adapts to different screen sizes, ensuring a seamless user experience across devices.
- **Dynamic Product Selection**: Users can select from a range of tech products including mobiles, laptops, tablets, and cameras.
- **Discount Calculation**: Discounts are calculated based on the user's roll number and can be enhanced with valid promo codes.
- **Price Summary**: Displays the original total, discount percentage, and final price after applying discounts.
- **Confirmation Alert**: Once the purchase is confirmed, a summary alert shows the total items purchased.

## Technologies Used

- **HTML**: Structure of the webpage.
- **CSS**: Styling for a modern, dark-themed user interface.
- **JavaScript**: Logic for product selection, discount calculation, and UI updates.

## How to Run

1. Clone the repository or download the HTML file.
2. Open the HTML file in any modern web browser.
3. Enter your roll number and promo code (if applicable).
4. Select the products you wish to purchase.
5. Click the "Confirm Purchase" button to see the total price and confirm your selection.
