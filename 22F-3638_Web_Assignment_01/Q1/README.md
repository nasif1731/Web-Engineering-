# Literary Treasures: 3D Book Cards 📚✨

I implemented this by using **HTML, CSS, and JavaScript** to create an interactive 3D book showcase. The design includes a **flip animation**, a **dark mode toggle**, and a dynamic book collection rendered via JavaScript.

## Features
- 📖 **3D Flip Animation** – Hover to reveal book details  
- 🌙 **Dark Mode Toggle** – Switch between light and dark themes  
- 🛒 **Add to Cart (Console Log)** – Click the button to simulate adding a book  

## How to Use
1. Clone the repository and open `index.html` in a browser.  
2. Hover over any book card to flip it.  
3. Click the 🌙 button to toggle between themes.  

## Tech Stack
- **HTML** – Structuring the bookshelf  
- **CSS** – Styling and animations  
- **JavaScript** – Dynamic content rendering and interactions  

🎨 Designed for a sleek, elegant digital bookshelf experience!
